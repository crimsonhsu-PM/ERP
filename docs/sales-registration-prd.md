# 營收登記頁面 PRD

## 1. 文件目的

本文件依照本機 3000DEV 營收登記頁面現況撰寫，定義 `/sales` 頁面的使用者故事、頁面元件、操作流程、欄位說明與資料來源，作為後續驗收、調整與開發對齊依據。

## 2. 產品背景

營收登記頁面用於記錄每日服務與商品收入。服務型品項只記錄收入；設定為需要庫存的實體商品在新增、更新或刪除銷售紀錄時，需同步建立或移除庫存異動紀錄，確保營收與庫存資料一致。

此頁屬於 ERP 受保護頁面，需具備 `sales` 頁面權限才能進入與呼叫相關 API。

## 3. 目標

- 讓營運人員快速建立每筆營收。
- 支援服務、課程、香油捐贈、實體商品等品項收入登記。
- 支援銷售人員、服務人員、付款方式與匯款資訊留存。
- 支援營收紀錄查詢、篩選、編輯、刪除與月份匯出。
- 商品銷售需自動產生庫存扣減紀錄。

## 4. 使用者故事

### US-01 新增營收

作為櫃台或營運人員，我想輸入銷售日期、客戶、銷售人員、付款方式與銷售明細，以便完成一筆營收登記。

驗收條件：
- 預設銷售日期為今天。
- 銷售人員為必填。
- 每筆銷售明細都必須選擇品項。
- 非香油捐贈品項必須選擇服務人員。
- 數量最小為 1。
- 選擇品項後，單價預設帶入品項售價，仍可手動修改。
- 新增成功後清空表單並重新載入列表。

### US-02 登記多筆銷售明細

作為營運人員，我想在同一次輸入中新增多筆明細，以便處理同一位客戶一次購買多個服務或商品的情境。

驗收條件：
- 可點擊「新增明細」增加明細列。
- 第一列不可刪除，第二列起可刪除。
- 每列可分別選擇品項、服務人員、數量與單價。
- 現況後端新增時會依每筆明細各建立一筆 `Sale`；編輯時可在同一筆 `Sale` 底下重建多筆 `SaleLine`。

### US-03 香油捐贈登記

作為營運人員，我想登記香油捐贈時不必填服務人員，以便符合沒有服務歸屬的收入情境。

驗收條件：
- 品項類型為 `OIL_DONATION` 時，服務人員欄位停用。
- 香油捐贈送出時不驗證服務人員。
- 後端不可要求香油捐贈明細帶服務人員。

### US-04 商品扣庫存

作為庫存管理者，我想商品銷售後自動扣庫存，以便庫存紀錄反映實際銷售。

驗收條件：
- 品項 `requiresInventory = true` 時，新增銷售後建立一筆 `InventoryMovement`。
- 庫存異動類型為 `SALE`。
- 異動數量為銷售數量的負數。
- 異動原因為 `銷售單 {saleId}`。
- 異動時間使用銷售日期。
- 編輯銷售時先刪除原銷售單對應庫存異動，再依新明細重建。
- 刪除銷售時同步刪除對應庫存異動。

### US-05 查詢與篩選營收

作為營運人員，我想依日期區間、客戶、銷售人員、服務人員篩選營收列表，以便快速查找紀錄。

驗收條件：
- 日期區間篩選包含起日與迄日。
- 客戶篩選使用不區分大小寫的包含查詢。
- 銷售人員與服務人員篩選使用員工下拉選單。
- 篩選在前端針對已載入列表即時套用。

### US-06 編輯營收

作為營運人員，我想修改既有營收紀錄，以便更正日期、客戶、付款方式、匯款資訊與明細。

驗收條件：
- 點擊列表操作欄的編輯按鈕後，資料帶回上方表單。
- 表單送出按鈕改為「更新」。
- 顯示「取消修改」按鈕。
- 更新成功後離開編輯狀態、清空表單、重新載入列表。
- 點擊「取消修改」後回到新增狀態。

### US-07 刪除營收

作為營運人員，我想刪除錯誤建立的營收紀錄，以便維持資料正確。

驗收條件：
- 點擊列表操作欄的刪除按鈕會呼叫刪除 API。
- 刪除成功後重新載入列表。
- 若正在編輯同一筆紀錄，刪除後表單回到新增狀態。
- 刪除時同步刪除該銷售單對應庫存異動。

### US-08 匯出營收 Excel

作為營運或財務人員，我想依月份匯出營收登記，以便製作對帳或報表。

驗收條件：
- 點擊下載圖示開啟「匯出營收 Excel」彈窗。
- 預設匯出月份為當月。
- 使用月份選擇器選定匯出月份。
- 點擊「匯出」後下載 `.xls` 檔。
- 檔名格式為 `營收登記-YYYYMM-YYYYMMDD-HHmm.xls`。

## 6. 操作說明

### 6.1 新增營收

1. 進入 `/sales`。
2. 確認或調整銷售日期。
3. 輸入客戶名稱。
4. 選擇銷售人員。
5. 選擇付款方式。
6. 如有匯款或付款備註，填寫匯款資訊。
7. 在銷售明細選擇品項。
8. 非香油捐贈品項需選擇服務人員。
9. 確認數量與單價。
10. 如需多筆明細，點擊「新增明細」並重複填寫。
11. 點擊「新增」送出。

### 6.2 編輯營收

1. 在列表找到要修改的營收。
2. 點擊編輯圖示。
3. 頁面捲動到上方表單。
4. 修改主檔或明細欄位。
5. 點擊「更新」。
6. 若不修改，點擊「取消修改」回到新增狀態。

### 6.3 刪除營收

1. 在列表找到要刪除的營收。
2. 點擊刪除圖示。
3. 系統刪除銷售單、銷售明細與該銷售單對應庫存異動。
4. 列表重新載入。

### 6.4 篩選營收

1. 使用日期區間篩選銷售日期。
2. 使用客戶欄輸入關鍵字。
3. 使用銷售人員下拉篩選銷售人員。
4. 使用服務人員下拉篩選服務人員。
5. 列表即時顯示符合條件的紀錄。

### 6.5 匯出 Excel

1. 點擊列表上方下載圖示。
2. 在彈窗選擇匯出月份。
3. 點擊「匯出」。
4. 系統下載該月份的營收 `.xls` 檔案。

## 7. 欄位說明

### 7.1 表單主檔欄位

| 欄位 | UI 元件 | 必填 | 預設值 | 資料格式 | 說明 |
| --- | --- | --- | --- | --- | --- |
| 銷售日期 | DatePicker | 否 | 今天 | `YYYY-MM-DD` | 寫入 `Sale.soldAt`。空值時回填今天。 |
| 客戶名稱 | Input | 否 | 空白 | 文字 | 寫入 `Sale.customerName`；空字串轉為 `null`。 |
| 銷售人員 | Select | 是 | 空白 | `Employee.id` | 寫入 `Sale.salesPersonId`；來源為啟用且具服務人員標籤的員工。 |
| 付款方式 | Select | 否 | `CASH` | `PaymentMethod` enum | 寫入 `Sale.paymentMethod`。 |
| 匯款資訊 | Input | 否 | 空白 | 文字 | 寫入 `Sale.notes`；可存匯款帳號、末五碼或付款備註。 |

### 7.2 銷售明細欄位

| 欄位 | UI 元件 | 必填 | 預設值 | 資料格式 | 說明 |
| --- | --- | --- | --- | --- | --- |
| 品項 | Select | 是 | 空白 | `Item.id` | 寫入 `SaleLine.itemId`；來源為啟用中的品項。 |
| 服務人員 | Select | 條件必填 | 品項預設服務人員或空白 | `Employee.id` | 非香油捐贈必填；目前儲存在 `Sale.servicePersonId`。 |
| 數量 | InputNumber | 是 | `1` | 正整數 | 寫入 `SaleLine.quantity`；最小值為 1。 |
| 單價 | InputNumber | 否 | 品項售價 | 數字 | 寫入 `SaleLine.unitPrice`；空白時後端使用 `Item.price`。 |
| 小計 | 系統計算 | 不適用 | 不適用 | 數字 | `unitPrice * quantity`，寫入 `SaleLine.lineTotal`。 |

### 7.3 系統計算欄位

| 欄位 | 資料表欄位 | 計算規則 | 說明 |
| --- | --- | --- | --- |
| 銷售小計 | `Sale.subtotal` | 明細金額合計 | 新增單筆明細時等於該明細金額；編輯時為全部明細合計。 |
| 折扣 | `Sale.discount` | 目前 UI 固定送出 0 | 頁面未提供折扣欄位。 |
| 銷售總額 | `Sale.total` | `max(0, subtotal - discount)` | 新增流程目前每筆明細各自建立銷售單，總額等於該明細金額。 |
| 狀態 | `Sale.status` | 預設 `CLOSED` | UI 未提供狀態切換。 |
| 庫存異動數量 | `InventoryMovement.quantity` | `-SaleLine.quantity` | 僅 `Item.requiresInventory = true` 建立。 |

## 8. 資料來源與 API

### 8.1 前端資料載入

頁面初始化時同時呼叫：

| API | 用途 | 前端處理 |
| --- | --- | --- |
| `GET /api/items` | 取得品項清單 | 僅保留 `active !== false` 的品項。 |
| `GET /api/employees` | 取得員工清單 | 僅保留 `active !== false` 的員工。 |
| `GET /api/sales` | 取得營收列表 | 依 `soldAt desc` 顯示。 |

### 8.2 員工資料篩選

銷售人員與服務人員下拉選單共用 `serviceEmployees`：

- 來源：`GET /api/employees`
- 條件：員工啟用，且員工標籤包含 `外部員工` 或 `內部員工`
- 顯示：`Employee.name`
- 值：`Employee.id`

### 8.3 品項資料

品項下拉選單來源：

- 來源：`GET /api/items`
- 條件：品項啟用
- 顯示：`{品項類型中文} - {品項名稱}`
- 活動品項：若 `Item.eventId` 有值，前綴顯示 `活動 -`
- 預設單價：`Item.price`
- 預設服務人員：`Item.servicePersonId`
- 庫存判斷：`Item.requiresInventory`

品項類型對照：

| enum | 顯示文字 |
| --- | --- |
| `DIVINATION_SERVICE` | 占卜服務 |
| `RITUAL_SERVICE` | 儀式服務 |
| `FENG_SHUI_SERVICE` | 風水服務 |
| `COURSE_SERVICE` | 課程服務 |
| `OIL_DONATION` | 香油捐贈 |
| `PHYSICAL_PRODUCT` | 實體商品 |

### 8.4 付款方式資料

付款方式來源為前端設定 `paymentMethods`：

| enum | 顯示文字 |
| --- | --- |
| `CASH` | 現金 |
| `TRANSFER` | 匯款 |
| `CARD` | 刷卡 |
| `LINE_PAY` | Line Pay |
| `OTHER` | 其他 |

### 8.5 營收 API

| API | 方法 | 用途 | 權限 |
| --- | --- | --- | --- |
| `/api/sales` | GET | 取得營收列表，包含銷售人員、服務人員、明細與品項 | `sales` |
| `/api/sales` | POST | 新增營收 | `sales` |
| `/api/sales/{id}` | GET | 取得單筆營收 | `sales` |
| `/api/sales/{id}` | PATCH | 更新單筆營收 | `sales` |
| `/api/sales/{id}` | DELETE | 刪除單筆營收 | `sales` |

### 8.6 Prisma 資料表

主要資料表：

- `Sale`：銷售主檔，儲存日期、客戶、銷售人員、服務人員、付款方式、總額與備註。
- `SaleLine`：銷售明細，儲存品項、數量、單價與明細金額。
- `Item`：品項主檔，提供品項名稱、類型、售價、是否需要庫存、預設服務人員。
- `Employee`：員工主檔，提供銷售人員與服務人員選項。
- `EmployeeTag`：員工標籤，用於篩選可用的銷售人員與服務人員。
- `InventoryMovement`：庫存異動，記錄商品銷售扣庫存。

## 9. 驗證與錯誤訊息

| 情境 | 驗證位置 | 錯誤訊息 |
| --- | --- | --- |
| 未選銷售人員 | 前端與後端 | 請選擇銷售人員。 |
| 明細未選品項 | 前端 | 請為每筆銷售明細選擇品項。 |
| 無有效明細 | 後端 | 請至少新增一個銷售明細。 |
| 明細品項不存在或停用 | 後端 | 銷售明細包含不存在或停用的品項。 |
| 非香油捐贈未選服務人員 | 前端與後端 | 請為每筆銷售明細選擇服務人員。 |
| 銷售日期格式錯誤 | 後端新增流程 | 銷售日期格式不正確。 |
| 新增 API 失敗 | 前端 | 新增營收失敗。 |
| 刪除 API 失敗 | 前端 | 刪除營收失敗。 |

## 10. 權限與導頁

- `/sales` 頁面進入前會檢查 `sales` 頁面權限。
- `/api/sales` 與 `/api/sales/{id}` 會檢查 `sales` API 權限。
- 未登入或無權限時依既有 ERP 權限流程導向登入頁或回傳權限錯誤。

## 11. 報表與下游影響

營收登記資料會被下列功能使用：

- Dashboard：今日營收、本月營收、每日營收圖、出售類型營收占比。
- 報表頁：營收、折扣、毛利、付款方式分析、品項收入分析、活動收入分析。
- 庫存紀錄：需要庫存的商品銷售會產生 `SALE` 類型扣庫存紀錄。

## 12. 現況限制與待確認

- 新增多筆明細時，後端目前會依每筆明細各建立一筆 `Sale`；這和 UI 上「同一張表單多明細」的直覺不同。若業務需要一張發票或交易單包含多明細，需調整 POST 行為。
- `SaleLine` 目前沒有 `servicePersonId` 欄位；服務人員儲存在 `Sale.servicePersonId`。編輯多明細到同一筆銷售單時，後端使用第一筆明細的服務人員作為整張銷售單服務人員。
- UI 固定送出 `discount: 0`，沒有折扣欄位。
- 刪除營收目前沒有二次確認彈窗。
- 列表篩選在前端執行，資料量大時可能需要改為 API 查詢。
- 匯出格式為 HTML table 包裝的 `.xls`，可被 Excel 開啟，但不是原生 `.xlsx`。

## 13. 驗收檢查清單

- 進入 `/sales` 可看到頁首、表單、銷售明細、列表、篩選與匯出按鈕。
- 新增一般服務營收成功，列表出現資料。
- 新增香油捐贈不需服務人員。
- 新增需要庫存的商品後，庫存紀錄出現 `SALE` 負數異動。
- 編輯營收後資料更新，相關庫存異動同步重建。
- 刪除營收後列表移除資料，相關庫存異動同步刪除。
- 日期、客戶、銷售人員、服務人員篩選皆可正常縮小列表。
- 月份匯出可下載符合月份的 `.xls` 檔。
